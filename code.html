Agents and Missions

A full-stack Java web application built with Spring Boot 4 and Thymeleaf. Agents and missions are modelled as a bidirectional many-to-many relationship through Spring Data JPA and Hibernate, so each agent's page lists their missions and each mission's page lists its assigned agents. The UI is server-rendered with Thymeleaf fragments for shared header and footer layout, styled with Bootstrap 5 alongside custom CSS, and includes agent creation forms and dedicated detail views. Sample data is seeded at startup by a DataInitializer component.
